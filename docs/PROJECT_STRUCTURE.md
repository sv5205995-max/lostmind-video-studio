# LOSTMIND Video Studio

A modular, free-first video editing and automation project.

## Project goals

Build three video workflows that share one rendering engine.

### Module A: RAW VIDEO
- Transcribe recorded speech
- Plan captions and cuts
- Select suitable B-roll
- Render vertical videos

### Module B: FACELESS AI REELS
- Create a topic-based script
- Prepare a scene-by-scene storyboard
- Add voiceover, visuals and captions
- Render a review-ready Reel

### Module C: CINEMATIC EXPLORER
- Plan mystery and exploration scenes
- Select suitable licensed footage
- Design atmosphere and sound
- Reveal visual anomalies gradually

## Planned technology
- HyperFrames: video composition
- FFmpeg: video processing and rendering
- Whisper: speech transcription
- n8n: workflow automation
- Telegram Bot: mobile control
- Local AI models: optional, depending on PC capacity

## Project principles
- Prefer free and open-source tools
- Keep API keys and passwords out of GitHub
- Use properly licensed media
- Review every video before publishing
- Keep cloud AI optional where practical
