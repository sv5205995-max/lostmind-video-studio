# LOSTMIND RAW VIDEO MODULE

## Purpose
Edit user-provided video footage.

## Planned workflow
1. Receive a source video.
2. Transcribe spoken audio.
3. Prepare captions and an editing plan.
4. Identify suitable B-roll and sound effects.
5. Compose a vertical 9:16 video.
6. Render an MP4 preview.
7. Review the result before publishing.

## Planned tools
- Whisper: speech transcription
- HyperFrames: captions and motion graphics
- FFmpeg: video and audio processing

## Current status
Planning stage. No automated editing code is implemented yet.

## Requirements
- Use media the user owns or is licensed to use.
- Keep source files separate from rendered output.
- Never publish automatically without configured permissions and review.
