# LOSTMIND FACELESS AI REELS MODULE

## Purpose
Create short-form videos without requiring an on-camera presenter.

## Planned workflow
1. Receive a topic or keyword.
2. Draft a short-form video script.
3. Split the script into scenes.
4. Prepare voiceover and visual assets.
5. Generate captions and motion graphics.
6. Add suitable background music and sound effects.
7. Render a vertical 9:16 MP4 preview.
8. Review the result before publishing.

## Planned tools
- Local AI model or optional cloud AI: script planning
- Whisper or compatible speech tools: transcription
- HyperFrames: video composition and graphics
- FFmpeg: media processing
- Optional text-to-speech engine: voiceover

## Cost policy
Prefer free and local tools where practical.
Cloud services may have usage limits or fees.

## Current status
Planning stage. No automated generation code is implemented yet.

## Safety and quality
- Use original scripts and properly licensed media.
- Review narration, captions and facts.
- Require approval before publishing.
