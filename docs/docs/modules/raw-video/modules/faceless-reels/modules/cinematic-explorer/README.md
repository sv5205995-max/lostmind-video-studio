# LOSTMIND CINEMATIC EXPLORER MODULE

## Purpose
Create atmospheric mystery and exploration short videos.

## Supported themes
- Dark caves and abandoned places
- Mountains and remote wilderness
- Deep ocean exploration
- Unexplained visual anomalies
- Adventure and discovery

## Planned workflow
1. Choose a topic and mystery.
2. Establish the environment before revealing anything unusual.
3. Build a scene-by-scene storyboard.
4. Select original or properly licensed footage.
5. Use realistic camera movement suited to the setting.
6. Reveal one memorable visual anomaly gradually.
7. Add environmental audio, sound design and captions.
8. Render a vertical 9:16 MP4 preview.
9. Review visual quality and factual claims before publishing.

## Visual principles
- Prefer believable explorer footage over overly polished AI visuals.
- Use flashlight and slow movement for cave scenes.
- Reflect wind and unstable footing in mountain scenes.
- Use water movement and limited visibility for ocean scenes.
- Use grain or monochrome only when the scene benefits from it.

## Planned tools
- HyperFrames: titles and motion graphics
- FFmpeg: rendering and audio processing
- Optional AI tools: scripts, storyboards and asset generation

## Current status
Planning stage. No automated production code is implemented yet.

## Publishing rule
Require human review before publishing.
